# Checklist de credenciais externas

Este arquivo é deliberadamente honesto: preparar material não equivale a
concluir uma avaliação ou receber badge.

## Microsoft Applied Skills

- [ ] Abrir o roteiro **Developing Agents in Microsoft Foundry**.
- [ ] Estudar deployment, token/TPM, agent instructions, tools, parâmetros e teste.
- [ ] Executar o laboratório prático com a conta Microsoft do usuário.
- [ ] Confirmar a credencial no perfil Microsoft Learn.
- [ ] Só depois copiar o nome para CV/LinkedIn.
- [ ] Repetir o processo para **Integrate Model Context Protocol tools with agents
  in Microsoft Foundry**.

## Cursos de conhecimento

- [ ] DeepLearning.AI Evaluating AI Agents — usar para conhecimento; accomplishment
  pode depender de plano da plataforma.
- [ ] Building and Evaluating Advanced RAG — validar acesso e registrar somente
  conclusão real.
- [ ] LangChain Academy Introduction to LangGraph — estudar os módulos essenciais.

## Hugging Face

- [ ] Completar Unit 1 do Agents Course.
- [ ] Fazer o quiz e obter pelo menos 80%.
- [ ] Confirmar certificado na conta.

## AWS

- [ ] Executar o hands-on Agentic AI Demonstrated no ambiente AWS.
- [ ] Confirmar o badge emitido no perfil.

## Regra de publicação

O repositório pode provar implementação, testes e métricas locais. Apenas o
usuário, na conta correspondente, pode provar identidade, conclusão e emissão
de credencial. Nenhum item acima é marcado como concluído automaticamente.
